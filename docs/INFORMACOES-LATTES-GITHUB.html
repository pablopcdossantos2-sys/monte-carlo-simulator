1. Classificação do projeto

Aplicação web educacional e simulador estatístico client-side para day trade.

Possui interface web completa, motor JavaScript de simulação, laboratórios estatísticos interativos, versão offline autocontida, testes automatizados e publicação estática via GitHub Pages.

5. Currículo Lattes

Português

Desenvolvimento independente de aplicação web educacional e simulador estatístico voltado a day traders, destinado ao estudo de probabilidade, expectativa matemática, risco e variabilidade em estratégias intradiárias. A ferramenta executa simulações de Monte Carlo paramétricas e históricas, análise de drawdown e sequências, regras de risco, laboratórios estatísticos interativos, análise por pregão e recursos didáticos de validação de estratégias. Concebida, implementada, integrada e verificada por Pablo Phillipe Cândido dos Santos, com utilização de ferramentas de inteligência artificial generativa como recurso auxiliar no processo de desenvolvimento. O projeto opera de forma client-side, com versão web estática e versão offline autocontida.

English

Independent development of a client-side educational web application and statistical simulator for day traders, intended to support the study of probability, mathematical expectancy, risk, and variability in intraday trading strategies. The tool provides parametric and historical Monte Carlo simulations, drawdown and sequence analysis, configurable risk rules, interactive statistics labs, session-level analysis, and educational strategy-validation resources. The project was conceived, implemented, integrated, and verified by Pablo Phillipe Cândido dos Santos, with generative AI tools used as auxiliary resources during development. It is available as a static web version and as a self-contained offline version.

7. Observações de coerência
